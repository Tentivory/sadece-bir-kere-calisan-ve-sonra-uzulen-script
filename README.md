# Sadece Bir Kere Çalışan ve Sonra Üzülen Script

## Giriş (Ciddi Olun)

Bu repository, modern yazılım mühendisliğinin en derin, en felsefi ve en üzücü problemini çözmeyi amaçlar: **Bir program neden sadece bir kez çalışmalıdır?**

Cevap basittir. Çünkü hayat böyledir. Bazen bir şey olur, sonra olmaz. Bu script de tam olarak budur.

## Özellikler (Abartılı)

- **Tek Seferlik Çalışma Garantisi**: %100, bir kez çalışır. İkinci kez çalıştırmaya kalkarsanız o da üzülür.
- **Gerçek Üzüntü Algoritması**: Rastgele felsefi çıktılar üretir. Hepsi üzücüdür.
- **Sıfır Bağımlılık**: Sadece Python. Ekstra kütüphane yok. Çünkü üzgün programlar bağımsız olur.
- **Sonsuz Üzüntü Potansiyeli**: Çıktıktan sonra asla geri dönmez.

## Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/sadece-bir-kere-calisan-ve-sonra-uzulen-script.git
cd sadece-bir-kere-calisan-ve-sonra-uzulen-script
python uzulen_script.py
```

**Uyarı**: Çalıştırdıktan sonra script üzülecek. Siz de biraz üzülebilirsiniz. Normaldir.
